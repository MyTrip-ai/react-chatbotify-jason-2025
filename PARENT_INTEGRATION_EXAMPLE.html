🚀 Onboarding Thread ID Integration

Example parent application demonstrating thread ID messaging to chatbot widget

📋 Instructions

  1. Click "Generate New Thread ID" to create a unique thread identifier
  2. Click "Send Thread ID to Chatbot" to send it to the widget via postMessage
  3. Start chatting - your conversation will be associated with this thread ID
  4. Navigate to another page or refresh, then send the same thread ID to continue the conversation

🎮 Controls

💬 Chatbot Widget

The chatbot widget will appear below. Replace the iframe src with your actual chatbot URL.

📝 How It Works

This example demonstrates the postMessage API to send the thread ID to the chatbot:

iframe.contentWindow.postMessage({
    type: 'thread_id',
    value: 'thread_1234567890_abc123'
}, '*');

The chatbot's useParentMessaging hook listens for this message and uses the thread ID in API calls.
